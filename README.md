# anal-sex-a-workbook

**Public.** Ten pages on the anal sex report (project 66 of the Venus session index), each a lesson, exercises, and the answers folded under them. Scale, the passage, per-act arithmetic, stacking protections, the other infections, HPV and the ANCHOR trial, pain, douching and lubricant, projections and assault, the law by case. A workbook you cannot check is a claim, so every answer is there to be checked.

## Files

- `workbook/67-anal-sex-workbook.html` — the workbook; open it. `workbook/66-anal-sex.html` is the report it tests, copied here so the links resolve; `workbook/style.css` is the shared stylesheet.
- `idle/anal-sex-a-workbook.html` — the idle game the index gives every project. It folds answers.
- `session-index.html` — the index this workbook is project 67 of.

## The invitation

- **Check an answer.** Every folded answer is arithmetic on a figure in the report. If the arithmetic is wrong, open an issue with the line.
- **Write page 11.** The economics: a course of PrEP against the lifetime cost of one infection, by country. The figures exist.
- **Add a case.** Page 10 tests the law; the report's country table has 64 criminalising jurisdictions. A judgment missing from either is wanted, with its date.

Nothing here needs permission. Pull requests that change a number must name the source.
